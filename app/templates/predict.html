How this number is produced

  1. Rating gap is {{ prediction.rating_a }} − {{ prediction.rating_b }} = {{ prediction.rating_gap }}{% if not prediction.neutral %}, plus a home bonus for {{ prediction.team_a }}{% endif %}.
  2. The Elo curve turns that gap into an expected score E = 1 / (1 + 10−gap/400).
  3. The draw rate for a gap this size is looked up from the calibration table below.
  4. Since E = P(win) + ½·P(draw), the three probabilities follow.
